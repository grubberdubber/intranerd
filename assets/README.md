# Activos de IntraNerd

## `brand/`

- `intranerd-mark.svg`: marca vectorial (libro abierto + gafas) para fondos claros.
- `intranerd-mark-inverse.svg`: variante para fondos azules/oscuros.
- `favicon.svg`: icono de pestaña y acceso directo.
- `source/`: los tres logos entregados por dirección. Se conservan como
  referencia para futuras campañas, merchandising o variantes de temporada.

## `mascots/`

- `nerdi.webp`: mascota oficial elegida, el búho **Nerdi**. Ilustración con
  fondo transparente y optimizada para web.
- `nerdi-head.webp`: recorte de la cabeza para avatares, badges o notificaciones.
- `alternativas/`: el niño y el robot de la lámina original, recortados y con
  transparencia. Quedan disponibles para actividades, talleres o futuras
  versiones de la mascota.
- `source/`: lámina original con las tres mascotas, conservada sin recortes.

## `fonts/`

Inter variable autoalojada (licencia OFL). No se hacen peticiones a Google
Fonts en tiempo de ejecución. `OFL.txt` conserva la licencia de la fuente.
